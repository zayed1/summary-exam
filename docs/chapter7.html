1 Attributes vs. Variables — the big picture

Attributes data classify each unit as conforming / nonconforming, or count defects. Two families of attribute charts:

p, np
Fraction / number nonconforming
(Binomial)
c, u
Number of nonconformities (defects)
(Poisson)
Key distinction

Nonconforming unit = a defective item (fails to meet specs). Nonconformity = a single defect; one unit may contain several nonconformities.

⚠ Recurring exam rule

For all four attribute charts: if the computed LCL < 0, set LCL = 0 (the chart then has only an upper control limit).

2 The p Chart — Fraction Nonconforming slides 7–14

The sample fraction nonconforming p̂ follows the binomial distribution. Its mean and standard deviation are:

μp̂ = p     σp̂ = √p(1 − p)n

Case A — Standard Given (p known) slide 8

Eq 7.6 UCL = p + 3√p(1 − p)n
CL = p
LCL = p − 3√p(1 − p)n

Case B — No Standard Given (estimate p) slides 9–10

Take m preliminary samples (rule of thumb m ≥ 20 or 25), each of size n. With Di nonconforming units in sample i:

p̂i = Din      p̄ = Σ Dim·n = Σ p̂im
Eq 7.8 UCL = p̄ + 3√p̄(1 − p̄)n
CL = p̄
LCL = p̄ − 3√p̄(1 − p̄)n
📊 Example 7.1 — Orange juice cans

m = 30 samples, n = 50 each. Total nonconforming ΣD = 347 ⟹ p̄ = 347 / (30·50) = 0.2313.

Trial limits: UCL = 0.2313 + 3(0.0596) = 0.4102, CL = 0.2313, LCL = 0.0524.

Samples 15 (new raw material) and 23 (new, inexperienced operator) plotted above UCL → assignable causes. Removing them and recomputing on 28 samples (ΣD = 301):

Revised: p̄ = 301/(28·50) = 0.2150 → UCL = 0.3893, CL = 0.2150, LCL = 0.0407.

3 The np Chart — Number Nonconforming slides 27–29

Instead of the fraction, plot the number nonconforming. Many non-statistical staff find it easier to read. (If p is unknown, use p̄.)

Eq 7.13 UCL = np + 3√np(1 − p)
CL = np
LCL = np − 3√np(1 − p)
📊 Example 7.2 — same OJ data

p̄ = 0.2313, n = 50:   CL = np̄ = 50(0.2313) = 11.565, UCL = 20.510, LCL = 2.620. In practice plot whole numbers (e.g. use 2 and 21 as LCL/UCL).

4 Variable Sample Size slides 31–33

When sample size n changes from sample to sample, there are three approaches:

I. Variable-Width Control Limits

Compute limits separately for each sample using its own size ni:

p̄ ± 3√p̄(1 − p̄)ni

II. Control Limits Based on an Average Sample Size

Use one set of approximate limits from the average size (assumes future sizes won't differ greatly):

n̄ = Σ nim  →  p̄ ± 3√p̄(1 − p̄)n̄

III. Standardized Control Chart

Plot points in standard-deviation units: center line = 0, UCL = +3, LCL = −3.

Zi = p̂i − p̄√p̄(1 − p̄)ni

5 OC Function & Average Run Length slides 34–37

The operating-characteristic (OC) curve plots the probability of a type II (β) error — incorrectly accepting "in control" — against the true fraction nonconforming. It measures the chart's sensitivity to a shift.

Eq 7.15 (β-error) β = P[p̂ < UCL | p] − P[p̂ ≤ LCL | p]
= P[D < n·UCL | p] − P[D ≤ n·LCL | p]

D is binomial(n, p), so β comes from the cumulative binomial. If LCL is negative, drop the second term.

Average Run Length (ARL) slide 36

ARL = 1P(point plots out of control)
In control:   ARL0 = 1α   ·   Out of control:   ARL1 = 11 − β
📊 ARL example (slide 37)

n = 50, UCL = 0.3697, LCL = 0.0303, center p̄ = 0.20. From the OC curve α = 1 − 0.9973 = 0.0027, so ARL₀ = 1/0.0027 ≈ 370 (a false alarm about every 370 samples).

If p shifts to 0.30, β = 0.8594, so ARL₁ = 1/(1 − 0.8594) ≈ 7 — about 7 samples to detect the shift.

6 The c Chart — Nonconformities (Defects) slides 40–47

Charts the total number of defects in an inspection unit, modeled by the Poisson distribution. This requires: (1) a very large number of opportunities for defects, (2) a small, constant probability of a defect at any location, and (3) the same inspection unit every sample.

p(x) = e−c cxx!,   x = 0,1,2,…    (mean = variance = c)

Case A — Standard Given (c known)

Eq 7.16 UCL = c + 3√c  ·  CL = c  ·  LCL = c − 3√c

Case B — No Standard Given (estimate c̄)

Eq 7.17 UCL = c̄ + 3√c̄  ·  CL = c̄  ·  LCL = c̄ − 3√c̄
📊 Example 7.3 — Printed circuit boards

26 samples, inspection unit = 100 boards. Total defects = 516 ⟹ c̄ = 516/26 = 19.85.

Trial: UCL = 19.85 + 3√19.85 = 33.22, CL = 19.85, LCL = 6.48.

Samples 6 (new inspector) and 20 (temperature-control problem) were out of control → removed. Revised: c̄ = 472/24 = 19.67 → UCL = 32.97, LCL = 6.36.

💡 Further analysis

Defect data are richer than fraction nonconforming: classify defects by type and use a Pareto chart to find the "vital few" (e.g. solder insufficiency & cold joints) feeding the out-of-control-action plans (OCAPs).

7 The u Chart — Nonconformities per Unit slides 52–56

When the sample contains n inspection units, chart the average defects per unit u = x / n (x is Poisson). The u chart should always be used when the sample size is variable.

Eq 7.19 UCL = ū + 3√ūn  ·  CL = ū  ·  LCL = ū − 3√ūn
📊 Example 7.4 — Supply-chain shipping errors

20 weeks, n = 50 shipments/week. Σ defects = 74 ⟹ ū = Σui/20 = 1.48/20 = 0.0740.

UCL = 0.0740 + 3√(0.0740/50) = 0.1894, CL = 0.0740, LCL = 0.0740 − … = −0.0414 → set LCL = 0.

Variable sample size on a u chart

Two options: (1) limits from average size n̄ = Σni/m; or (2) the standardized chart (preferred), with CL = 0, UCL = +3, LCL = −3:

Zi = ui − ū√ūni

8 Demerit Systems slides 57–58

For complex products, not all defects are equally important, so classify them by severity and assign weights:

ClassSeverityWeight
AVery serious (unfit / unsafe)100
BSerious50
CModerately serious10
DMinor1

Demerits in inspection unit i, and demerits per unit for a sample of n units (D = Σdi):

Eq 7.21–7.22 di = 100ciA + 50ciB + 10ciC + ciD   ·   ui = Dn
Eq 7.23–7.25 CL = û = 100ūA + 50ūB + 10ūC + ūD
UCL / LCL = û ± 3σ̂u
σ̂u = √(100²ūA + 50²ūB + 10²ūC + 1²ūD)n

9 Choosing the Right Chart & Improving the Process slides 59–66

Attributes vs. Variables charts slide 59

Attributes (p, np, c, u)Variables (x̄–R, x̄–s)
Several characteristics judged jointly (conform / not)More information about process performance
Often easier & cheaper to collectGives advance warning before defects occur
Usually needs larger samplesNeeds smaller samples

Which chart type? slides 62–64

  • x̄ and R (or x̄ and s): new process; tight/overlapping tolerances; diagnosing a chronically troubled process; when destructive testing or reduced sampling is wanted.
  • Attributes (p, c, u): operators control assignable causes; complex assembly; process control needed but measurement data unavailable; management summaries.
  • Individuals (x) + moving range: one measurement per unit (e.g. chemical processes), or data available very slowly.

Actions taken to improve a process slide 65

Decisions depend on two questions — is the process in control? and is it capable?

CapableNot capable
In controlSPCSPC · Experimental design · Investigate specs · Change process
Not in controlSPCSPC · Experimental design · Investigate specs · Change process
💡 Placement guideline

The earlier in the process that control can be established, the better. As knowledge grows, charts often shift toward attributes near the end of manufacturing, while x̄–R charts move earlier to the critical parameters.

★ Quick Review

  • Nonconforming (defective) → Binomial → p & np charts.
  • Nonconformities (defects) → Poisson → c & u charts.
  • p = fraction, np = number, c = defects per (constant) inspection unit, u = defects per unit (and for variable sample size).
  • Variable n: variable-width limits · average-size limits · standardized chart (CL 0, ±3).
  • OC curve shows β; ARL₀ = 1/α, ARL₁ = 1/(1−β); larger n ⟹ faster detection.
  • Demerit weights: A = 100, B = 50, C = 10, D = 1.
  • Always set LCL = 0 if negative; estimate parameters from ≥ 20–25 samples.
