# ملخّصات الاختبارات 📚

موقع ملخّصات دراسية منظّمة، صفحة مستقلّة لكل مادة، تعمل على الجوال والكمبيوتر **بدون إنترنت** (الخط العربي مضمّن).

## 🌐 الموقع المنشور

**https://zayed1.github.io/summary-exam/**

> إن لم يفتح الرابط بعد، راجع قسم «تفعيل النشر» في الأسفل.

## 📑 المواد المتوفّرة

| المادة | الوصف | الصفحة |
|--------|-------|--------|
| **السيرة النبوية** (المادة الحالية) | ملخّص شامل لكتاب **«دراسات في السيرة النبوية»** (جامعة الملك سعود) — الوحدات الاثنتا عشرة كاملة، مع إبراز المصطلحات والتواريخ والأسماء والأحداث وجداول الغزوات. | [seerah.html](docs/seerah.html) |
| **ضبط الجودة الإحصائي (SQC)** | أرشيف ملخّصات مادة *Statistical Quality Control (1405-433)* — الفصول 1، 5، 7، 8، 15 بالإنجليزية بمصطلحات الكتاب. | [sqc.html](docs/sqc.html) |

> المرجع الأساسي للسيرة: *دراسات في السيرة النبوية*، تأليف مجموعة من المتخصصين في العلوم الشرعية، نشر دار جامعة الملك سعود للنشر (الإصدار الخامس).

## ✨ مميّزات ملخّص السيرة

- **تلخيص للكتاب كامل** (12 وحدة + المقدمة + الخاتمة) دون استثناء شيء مهم، بشكل مرتّب.
- المحافظة على **المصطلحات** كما هي، مع إبرازها بلون مميّز.
- ترميز لوني للعناصر القابلة للسؤال: **المصطلحات / التواريخ / الأسماء / الأماكن / الآيات**.
- **جدول جامع للغزوات** (التاريخ، العدو، الأعداد، النتيجة) للمراجعة السريعة.
- **مرجع رقم صفحة الكتاب** بجانب كل وحدة.
- زر **«طباعة / حفظ PDF»** لتصدير أي صفحة كملف PDF.

## 🚀 تفعيل النشر (GitHub Pages) — خطوة واحدة لمرة واحدة

1. افتح **Settings → Pages**.
2. في **Build and deployment → Source** اختر **Deploy from a branch**.
3. اختر الفرع **`main`** والمجلد **`/docs`**، ثم **Save**.
4. خلال دقيقة سيظهر الموقع على الرابط أعلاه، وسيتحدّث تلقائياً مع كل تحديث.
