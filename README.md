# ملخصات المادة 📚

هذا المستودع مُجهَّز لاستقبال ملفات المادة الدراسية وإنشاء ملخصات لها، مع التركيز على **الصفحات المحددة** فقط (الأمور المهمة التي حددتها الدكتورة) وتجاهل الحشو.

## 📁 بنية المستودع

```
.
├── source-files/     ← ضع هنا ملفات المادة الأصلية (PDF / Word / صور ...)
├── summaries/        ← ستظهر هنا الملخصات الجاهزة
└── README.md         ← هذا الملف
```

## 🔄 طريقة العمل

1. **ارفع الملفات**: ضع ملفات المادة داخل مجلد `source-files/`.
2. **حدّد الصفحات**: أخبرني باسم كل ملف والصفحات المطلوبة منه. مثال:
   - `محاضرة1.pdf` → الصفحات 5، 8، 12 إلى 15
   - `الفصل-الثاني.pdf` → الصفحات 20–25 و 30
3. **التلخيص**: سأقرأ الصفحات المحددة فقط، وأستخرج النقاط المهمة، وأكتب ملخصاً منظّماً لكل ملف داخل `summaries/`.

## ✅ ملاحظات

- يُفضّل أن تكون الملفات بصيغة **PDF** أو **صور واضحة** ليسهل قراءتها.
- إذا كان الملف ممسوحاً ضوئياً (صورة) سأقرأ النص منه بصرياً.
- كل ملخص سيُحفظ بنفس اسم الملف الأصلي مع لاحقة `-ملخص.md`.
